Procedures

Power, volume, squelch, NAV volume
  • Power on: turn PWR/VOL clockwise past the detent. Power off: turn counter-clockwise past 0.
  • Press the COM knob to toggle the automatic squelch override. SQ appears top-left.
  • The NAV knob (bottom left) sets the NAV audio volume.
1.2 Keys: C/N, OBS, T/F
  • C/N selects the COM or NAV (VLOC) radio mode. The COM or NAV annunciator shows on the top line.
  • OBS shows the OBS setting and graphic CDI. T/F toggles bearing TO / radial FROM the active VOR, with distance/speed/time.
  • There is no MEM or ICS key: recent and user lists and the ICS settings are in the FUNC menu.
2.1 COM: select / flip / monitor
  1. Press C/N if needed to reach COM.
  2. Outer knob = MHz (118–136), inner knob = kHz (25 or 8.33 steps).
  3. Press ⇄ to swap active and standby. Flip is disabled while transmitting.
  4. MON: MN replaces STB. A signal on the active frequency takes priority; monitoring stays on in NAV mode.
2.1.3 / 2.2.2 Save a channel
  1. On the COM or NAV page press ENT.
  2. Inner knob = character, outer knob = cursor.
  3. After selecting characters, press ENT. Turn the outer knob to the TYPE field, inner knob selects the type (NAV: VOR, DME, LOC, ILS, 01–36).
  4. ENT saves (max 15), CLR cancels.
2.1.4 / 3.3.3 Database look-up
  1. On the COM or NAV page press the inner knob (PUSH CRSR).
  2. Inner knob = character, outer knob = cursor. COM: LKLT, LKPR, LKAA. NAV: OKL, NER, VOZ, BNO, PR (LKPR ILS 24).
  3. ENT, inner knob selects the type. NAV: if DUPLICATES FOUND, ENT, inner knob selects the station, ENT.
  4. ENT = standby, ⇄ = active.
2.2 NAV: select / ident
  1. Press C/N to reach NAV.
  2. Outer knob = MHz (108–117), inner knob = kHz (50 kHz steps).
  3. The identifier shown comes from the database, not from the decoded Morse ident.
  4. ⇄ swaps the NAV frequencies.
  5. Press the NAV knob (NAV display active): ID appears and the Morse ident is heard.
2.3 OBS / CDI
  • Press OBS. Bottom line: decoded ident, OBS setting, CDI (5 dots each side, 2° per dot, 10° full scale), TO/FROM triangle, active COM frequency.
  • Outer knob changes the OBS in 10° steps, inner knob in 1° steps. Fly towards the bar to be on course.
  • Use the Flight panel (ground speed, track, Fly) to practice intercepting radials.
2.4 T/F: distance / speed / time
  • Press T/F: the bottom line shows ident, bearing TO (or radial FROM), distance, ground speed, time to station and the active NAV frequency.
  • Press again to toggle TO / FROM. Needs a GPS source; stations within 200 NM. Does not operate on localizer frequencies.
2.1.5 Emergency / 2.1.6 stuck mic / 2.1.8 remote
  • Hold ⇄ (or COM RMT XFR) about 2 s: 121.500 becomes active, old active to standby.
  • Hold COM RMT XFR 2 s: COM locked to 121.5; hold again to unlock (or cycle power).
  • PTT held > 30 s raises REMOTE KEY STUCK; at 35 s the radio returns to RX and shows STUCK MIC until released.
  • Remote recall loads the next COM user preset into standby.
3.2 / 3.3 FUNC: COM and NAV lists
  1. FUNC. Outer knob = category (COM FREQUENCY LIST, NAV FREQUENCY LIST, ICS, SYS, TMR), inner knob = item, ENT opens.
  2. Lists: inner knob scrolls, ⇄ = active, ENT = standby, CLR returns to the functions display.
  3. User freqs: CLR then ENT deletes; press the inner knob to edit.
  4. NEAREST APT/ACC/FSS/WX and NEAREST VOR need a GPS position.
3.4 ICS / 3.5 SYS
  • FUNC → ICS CONFIGURATION: Adjust Intercom (needs intercom ON), AUX Audio, Intercom On/Off, Speaker On/Off.
  • FUNC → SYS CONFIGURATION: COM spacing, sidetone, DSPL BRT, DSPL CONTRAST, database info / load, software version, serial number.
3.6 Timers
  • FUNC → TMR CONFIGURATION → COUNT DOWN / COUNT UP.
  • Count down: press the inner knob to set the start time, ENT to accept; ENT start/stop, CLR reset to the start value.
  • Count up: ENT start/stop, CLR reset to 0.
  • On the COM/NAV page: CLR then ENT = reset, ENT twice = stop.
5.1 Messages
  • Messages take over the display. ENT acknowledges and returns to the previous page.
  • Raise any of them from the Simulation panel to practice.
