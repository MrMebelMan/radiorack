Procedures

Mode selector knob
  • OFF power removed · SBY on, no replies · GND replies to Mode S ground interrogations · ON replies, altitude suppressed · ALT replies to all.
  • Airborne: ALT unless ATC directs otherwise. Taxiing: GND. With a squat switch it switches automatically.
Squawk code / Flight ID
  1. FLT/SQ selects which one is shown big and changed.
  2. Turn the code knob: the first digit is highlighted and changes.
  3. ENT advances to the next digit, BACK goes back.
  4. ENT on the last digit replaces the value. Not completed within 7 s: changes ignored.
  5. Flight ID: letters and digits only; enter a blank to end it if shorter than 8.
  6. 1200 VFR (USA) · 7000 VFR (Europe) · 7500 hijack · 7600 loss of communications · 7700 emergency.
IDENT / VFR
  • IDENT when ATC asks to "Ident" / "Squawk Ident": SPI for 18 s, IDENT on the display.
  • VFR sets the pre-programmed code; press again to restore the previous code.
FUNC: flight timer, timer, altitude monitor
  • FUNC steps through the pages: FLIGHT TIME, TIMER, ADS-B monitor (if installed), ALTITUDE MONITOR.
  • Flight time: time powered on in ON or ALT.
  • Timer: ENT resets and starts, ENT again stops.
  • Altitude monitor: ENT toggles it at the current altitude; alert when more than 250 ft off. A small pointer appears next to the altitude.
Warnings / faults
  • WARNING + statement: note it, ENT clears; it reappears if the problem is still present.
  • FAULT + statement: no replies. Some faults clear by switching off and on.
