Procedures

Power, volume, squelch
  • Power on: turn PWR/VOL clockwise past the detent (scroll up). Power off: turn counter-clockwise past 0.
  • Press the knob to toggle the automatic squelch override. SQ appears top-left.
  • The volume bar graph shows while you turn the knob.
2.1 Select a frequency / flip
  1. Press COM if needed.
  2. Outer knob = MHz (118–136), inner knob = kHz (25 or 8.33 steps).
  3. Press ⇄ to swap active and standby. Flip is disabled while transmitting.
  4. With GPS: the nearest station ident/type shows under each frequency. * = more than one type.
2.2 Monitor standby (MON)
  • Press MON: MN replaces STB and you hear standby too.
  • When the active frequency receives a signal, the radio switches to it automatically, cutting off the standby audio. Once the active goes quiet, the standby is heard again. Active audio quality is not affected.
  • Press MON again to turn monitoring off. With MON off, standby transmissions are not heard.
  • Practise it: press Incoming call on STANDBY, then Incoming call on ACTIVE while the standby call is playing.
2.3 Save standby as user freq
  1. On the COM page press ENT.
  2. Inner knob = character, outer knob = cursor.
  3. After selecting characters, press ENT. Then turn the outer knob to the TYPE field and the inner knob to select the type.
  4. ENT saves (max 15), CLR cancels.

If a timer is running and shown, ENT on the COM page opens the STOP TMR prompt instead.

2.4 Database look-up
  1. On the COM page press the inner knob (PUSH CRSR).
  2. Inner knob = character, outer knob = cursor (auto-completes). Try LKLT, LKKB, LKMB, LKPR, LKAA (Praha FIR / Information).
  3. ENT, then the inner knob scrolls types (+ = more freqs of the same type).
  4. ENT = to standby, ⇄ = to active. Remembered for 30 min.
2.5 Emergency / 2.6 stuck mic / 2.8 remote
  • Hold ⇄ (or the COM RMT XFR) about 2 s: 121.500 becomes active and the old active moves to standby.
  • Hold COM RMT XFR 2 s: COM is locked to 121.5. Hold again to unlock (or cycle power).
  • PTT held > 30 s raises the REMOTE KEY STUCK message. At 35 s the radio returns to RX and shows STUCK MIC until you release.
  • Remote recall: each press loads the next user preset into standby (wraps).
3.2 MEM: recent & user lists
  1. MEM = recent (last 20). MEM again = user list.
  2. Inner knob scrolls. ⇄ = set active, ENT = set standby.
3.2.2 Edit / delete user freq
  1. FUNC → USER FREQS → ENT, inner knob to an entry.
  2. Delete: CLR, then ENT to confirm.
  3. Edit: press the inner knob. Inner knob sets MHz, outer knob to the kHz field, inner knob sets kHz, outer knob to the WPT field (inner = character, outer = cursor). Press ENT, turn the outer knob to the TYPE field, inner knob selects the type. ENT accepts, CLR cancels. Use the empty slot to add a new entry.
3.2.3–3.2.7 FUNC: database & nearest
  1. FUNC. Outer knob = category, inner knob = item, ENT opens.
  2. NEAREST APT: inner knob scrolls the 25 nearest airports, ENT shows that airport's frequencies; then inner knob selects, ⇄ = active, ENT = standby, CLR = back.
  3. NEAREST ACC/FSS/WX: inner knob scrolls, ⇄ = active, ENT = standby, CLR returns to the functions display.
  4. Needs a GPS position (see the Simulation panel).
3.3 ICS settings
  • ICS key cycles Adjust Intercom → AUX Audio → Intercom On/Off → COM page.
  • Adjust Intercom (needs intercom ON): SQ (one click below 0 = AUTO), VOL, MUTE ON RX. Outer knob = field, inner knob = value.
  • ENT saves, CLR undoes. The speaker setting is under FUNC → ICS CONFIGURATION.
3.4 System configuration
  • COM SPACING 8.33/25. Switching to 25 kHz deletes 8.33-only user frequencies.
  • COM SIDETONE: OFFSET/FIXED, offset −10…10.
  • DSPL BRT −10…100, DSPL CONTRAST −50…50.
  • DATABASE INFO, SOFTWARE VER, SERIAL NUMBER: press FUNC to exit.
  • LOAD DATABASE: insert USB (Simulation panel), ENT, check the versions, ENT, wait.
3.5 Timers
  • FUNC → TMR CONFIGURATION (outer knob) → COUNT UP / COUNT DOWN.
  • Count up: ENT start/stop, CLR reset to 0.
  • Count down: press the inner knob to set the start time (outer knob = H/M/S field, inner knob = value), ENT to accept. Then ENT start/stop, CLR reset to the start value.
  • On the COM page the running timer shows bottom-right (countdown first). At 0 the countdown keeps counting up, highlighted.
  • On the COM page: CLR then ENT = reset, ENT twice = stop.
5.1 Messages
  • Messages take over the display. ENT acknowledges and returns to the previous page.
  • Raise any of them from the Simulation panel to practice.
