Procedures

Mode selection keys
  • STBY, ON or ALT powers on with the last code; a start-up page shows during the self test. OFF powers off.
  • STBY no replies · ON Mode A (and S), no altitude · ALT Mode A, C and S with pressure altitude.
  • Press and hold STBY: GND (when not selected automatically). With automatic airborne determination GND is shown on the ground.
  • The reply symbol ® shows when the transponder replies.
Code selection
  1. Keys 0–7: the first key starts the entry; digits not yet entered appear as dashes.
  2. The new code is active when the fourth digit is entered.
  3. CLR goes back one digit; on the first digit (or CRSR) the entry is cancelled and the previous code restored.
  4. CLR up to five seconds after the entry returns the cursor to the fourth digit.
  5. 1200 VFR (USA) · 7000 VFR (Europe) · 7500 hijack · 7600 loss of communications · 7700 emergency.
IDENT / VFR
  • IDENT: SPI pulse for 18 s, IDENT in the upper left corner.
  • VFR: the pre-programmed VFR code; press again to restore the previous code.
FUNC pages and timers
  • FUNC: PRESSURE ALT, FLIGHT TIME, ALT MONITOR, (OAT/DALT), COUNT UP, COUNT DOWN, (CONTRAST, DISPLAY).
  • Flight time: START/STOP pauses or restarts, CLR resets (automatic start and stop when configured).
  • Count up: CLR resets, START/STOP starts and pauses.
  • Count down: CRSR, then all six digits with 0–9 (leading zeros too); START/STOP runs and pauses; at zero EXPIRED flashes and the time counts up; CLR resets to the initial time.
  • Altitude monitor: at the assigned altitude press START/STOP; again to cancel. Over the limit: voice "Leaving Altitude" and the annunciator.
Flight ID at power-up
  1. The FLT ID field is highlighted. If it is correct: CRSR to OK?, CRSR again to accept.
  2. To change it: number keys, pressed repeatedly for the letters (R = 5 four times); CRSR to the next character, CLR back.
  3. After the last character CRSR to OK?, CRSR accepts. Wrong FLT ID found later: turn off and on and enter it again.
Configuration pages (installer)
  • Power off; right-click FUNC to keep it pressed, then press ON. Release FUNC.
  • FUNC next page, START/STOP back to the menu page, CRSR selects a field and accepts it, 8/9 change a list, 0–9 enter numbers.
  • Turn the power off to leave.
